# Contributing

Thanks for helping. TradStrat's value is that its numbers can be trusted, so every change is held to that.

## Set Up

```bash
git clone https://github.com/Elarionitis/TradStrat.git
cd TradStrat
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Before You Open a Pull Request

```bash
ruff check . && ruff format --check .   # Lint and formatting
mypy                                     # Types
pytest --cov                             # Tests, which must keep coverage above 90%
python scripts/mutation_check.py         # Optional: confirms the tests catch injected bugs
```

The test suite blocks network access, so tests never depend on Yahoo Finance being available.

## Adding a Strategy

Write one class in `tradstrat/strategies.py` with the `@register` decorator, as the README shows. The
dashboard, command line, optimizer and look-ahead tests pick it up automatically. Its signal on each bar may
use data up to and including that bar, and nothing later.

## Ground Rules

- **No look-ahead.** A decision may only use information available when it is made. If you touch the engine,
  add a test that rewrites future bars and checks that past results do not change.
- **Report undefined numbers as `NaN`, not zero.** A zero ranks a strategy that never traded above one that
  lost money.
- **Keep claims reproducible.** Anything stated in `docs/RESULTS.md` is generated by
  `scripts/run_research.py`.
- **Explain why, not what,** in comments and commit messages.
